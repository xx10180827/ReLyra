# 双人 LAN 测试包

将整个 `Windows` 文件夹复制到第二台 Windows 电脑，双方使用同一份包。不要只复制 exe；不需要安装 UE 编辑器。`Start-LAN.cmd` 应与 Windows 根目录的 `LyraGame.exe` 放在一起，双击启动。

首次启动若提示运行库缺失，运行 `Engine/Extras/Redist/en-us/UEPrereqSetup_x64.exe`。双方连到同一个局域网；Windows 防火墙若询问，允许此游戏通过当前可信的专用网络。测试工具不会替你修改防火墙。

## 创建和加入

1. 房主从原主菜单的 LAN 入口进入房间菜单，选择地图和队伍，创建房间。
2. 第二台电脑从相同入口搜索房间并加入；搜索不到时，输入房主的局域网 IPv4 地址和端口，例如 `192.168.1.10:7777`。跨电脑不要用 `127.0.0.1`。
3. 可以选择同队；只能入房前选队，进入后整局锁队，死亡也不能换队。离开房间后可重新选择。
4. 每房最多两名真人；满房时第三个独立游戏进程应被拒绝。AI 不计入两人限制。

## 操作和规则

- 移动、开火、换弹、切枪及 TopDown 炸弹沿用对应地图原操作。
- `I` 打开／关闭背包；在背包中拖动整理，选择物品后通过界面按钮装备、使用、拆分或丢弃。
- 靠近地面物品后按 `E` 拾取。背包里的弹药必须手动“使用”才补充当前对应武器的备弹；步枪备弹上限 90。
- `F10` 打开房间菜单，可以离开房间。房主离开或关闭游戏后，客户端应返回可重新连接的菜单。
- 五图保留原玩法。背包试验场与两张射击地图在同局死亡后重生，背包按当前同局保留规则恢复；两张 TopDown 地图保留死亡淘汰，不额外添加自动重生。
- 离开、重开或更换关卡后，背包不跨关卡继承。

## 第二台电脑待测项

本机双进程测试不能代替以下双物理机结果，请记录双方实际情况：

| 检查 | 预期 |
|---|---|
| LAN 搜索、直接 IP 加入 | 双方进入同一地图，可见彼此移动 |
| 五图逐一建房和加入 | 原玩法、HUD／计时、背包入口正常 |
| 晚加入、同队与异队、满房第三人 | 已有状态正确；整局锁队；第三人被拒 |
| 抢同一物品、丢弃后对方拾取 | 总数守恒，武器弹匣／备弹状态保留 |
| 背包手动使用弹药、换弹／切枪 | 不自动补备弹，步枪上限 90，双方表现正确 |
| 真实死亡／重生或淘汰 | 符合各地图规则；未串包、重复领取或丢失同局库存 |
| 客户端退出重入、房主退出、重新建房 | UI 和输入恢复；新关卡不继承旧背包 |

发生问题时保存双方 `Lyra/Saved/Logs` 日志，并注明地图、房主／客户端、操作和出现时间。请勿把旧包与修复后的包混用。

## 版本与测试状态

这是 Development 测试包，最终验收由用户完成。包内 `BuildInfo.json` 记录构建编号和运行复测状态：`Pending` 表示尚未完成复测，不能当作已验证版本；双物理机 LAN 结果独立记录。

修复前曾有射击图 Niagara 模板丢失（PACK-003）和延迟网络下开火标签移除错误（GAS-001），历史失败记录保留在项目《背包与双人联机任务文档.md》第 5.18 节。修复包的具体复测结论见该文档后续记录及 `BuildInfo.json` 指向的报告。

Development 包仍有 `L_FiringRange_WP` 主资产 ID 等黄色 Warning 提示。遇到新的红色错误、崩溃或玩法异常，请按上述方式保存双方日志，不以本机自动测试代替实际体验验收。
