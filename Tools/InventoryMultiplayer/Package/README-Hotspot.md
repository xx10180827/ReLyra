# 保留 VMware 的热点专用启动文件

2026-10-24 用户已确认：使用本版启动文件，VMware 保持启用时双方均能搜索到房间。验收范围为当前两台电脑与热点地址，不代表自动适配任意网卡或地址。

1. 将两个 .cmd 放到现有游戏包 Windows 目录，与根目录 LyraGame.exe 并排；无需重新复制整个游戏包。
2. 双方连接好热点，退出旧游戏。VMware 保持启用。
3. 你的电脑（本机 IPv4 192.168.132.98）运行 Start-LAN-Hotspot-98.cmd。
4. 另一台（本机 IPv4 192.168.132.239）运行 Start-LAN-Hotspot-239.cmd。两台不要运行同一个文件。
5. 从新增双人 LAN 入口创建房间，对方搜索；再交换房主重复。记下时间，保留双方 Lyra/Saved/Logs。

这些文件直接启动游戏，不调用 PowerShell／网卡管理命令，不禁用 VMware、不改防火墙／路由／系统配置。它们使用 UE 的 MULTIHOME 参数，仅指定本次游戏进程的本机地址。日志会记录实际绑定地址。

IP 是各自电脑的本机 IP，不是房主 IP。热点重新分配地址或切换网络后，先退出游戏并更新启动文件；不存在所需本机 IP 时文件会提示而不启动。需要恢复默认行为时，退出后用原 Start-LAN.cmd 即可。

该方案与旧候选使用同一种 UE 绑定机制，但移除了自动选卡 PowerShell 依赖，明确指定两端已知热点地址。该地址组合已通过用户双机搜索验收；若网络或地址变化后失败，应继续分析绑定后的广播是否抵达。
